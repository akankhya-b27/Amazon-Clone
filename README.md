# Amazon Clone

This is a simple frontend clone of the Amazon homepage made using HTML and CSS.

## Technologies Used

* HTML
* CSS

## About the Project

I made this project while learning frontend web development. The main purpose was to practice HTML and CSS by recreating the basic layout and design of the Amazon homepage.

The project includes a navigation bar, search bar, product sections, images, and a footer.

## How to Run

Clone the repository or download the files and open `index.html` in a browser.

You can also use Live Server in VS Code to run the project.
